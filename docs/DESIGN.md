# MiniStation 界面设计

面向企业模型工程师与运维人员，主要任务是判断服务能否上线、定位失败步骤并管理调用权限。桌面侧栏固定分组，主区域采用工具栏、表格与右侧详情抽屉；部署操作使用分步表单，编排采用可编辑树和关系图。没有数据时展示接入行动，不预填虚假集群、曲线或账单。

配色：导航深蓝 #153B56，操作蓝 #1769AA，底色 #F3F6F9，内容白 #FFFFFF，正文 #172B3A，成功青 #087F72。橙色仅用于待处理事项。字体使用系统 Segoe UI 与微软雅黑，数字采用等宽数字，代码用 Consolas；不依赖外网字体。间距以4px为单位，边框区分区域，少量圆角用于交互控件，不使用渐变和装饰阴影。

信息层级：全局项目 → 能力域 → 服务或资产 → 修订与操作。绿色必须同时显示状态文字。加载、失败、未配置、空列表分别展示。密钥仅创建时展示一次；危险操作明确确认。原生dialog提供焦点约束、Escape关闭，所有输入有label；窄屏侧栏折叠，数据表局部滚动。

技能建议中的营销Hero结构不符合本项目任务，采用高密度运维台布局。辨识点是服务从资产、部署、发布到调用的四段运行状态条，全部来源于后端真实记录。
