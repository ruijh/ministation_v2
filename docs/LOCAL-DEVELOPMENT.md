# 当前环境可推进的功能

依据 README 与 COVERAGE 的待开发事项，当前 Windows / WSL / 三节点 kind、无 GPU 环境适合以下工作。其中 Webhook、隔离升级恢复演练与项目级请求队列已实现并通过本地测试，使用方法见 [运维指南](DELIVERY.md)；六入口轻量导航、目标环境检测与保守资源推荐、已有模板适配提示、部署向导、接入发布引导与结构化诊断也已实现，见 [部署与调用指南](DEPLOYMENT-GUIDE.md)；其余为候选事项。

| 候选功能 | 当前可完成的验证 | 仍需补充的条件 |
| --- | --- | --- |
| 通用 Webhook 告警 | 本地接收端、签名、超时、重试、去重与失败记录 | 飞书、企业微信等真实渠道配置 |
| 升级迁移与恢复演练 | 隔离数据库迁移、版本兼容、备份校验与恢复后业务验证 | 外部卷、异机灾备和真实 RTO/RPO 验收 |
| 网关请求排队 | 上限、取消、超时、租户隔离、预算与排队交互 | 生产并发容量与多实例协调 |
| 发布审批 | 角色分离、审批状态、审计、未批准版本禁止发布 | 企业审批制度接入 |
| 模型导入增强 | 断点导入、哈希校验、小文件分片完整性与损坏拒绝 | 大模型导入性能和设备兼容 |
| 节点排空预检 | Pod/PDB 检查、阻塞提示与临时工作负载驱逐流程 | 跨物理机故障域和生产业务保护 |
| 容器及离线交付工具 | 构建、镜像导入、依赖清单和禁网启动 | 干净环境完整离线安装复验 |
| PD 管理与路由 | 参数、UI、清单、配额、协议和故障测试 | GPU 模型计算、真实 KV 传输及性能 |

轻量级平台优先完善模型导入和现有部署调用体验；发布审批与节点排空根据实际场景按需考虑。生产控制面/数据面高可用、GPU 采集认证和硬件最优参数认证不能以当前单机测试替代。
