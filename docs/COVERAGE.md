# 功能覆盖与交付范围

本文说明 MiniStation 当前 Windows 开发验证版的功能范围。各功能域统一按“已实现功能”和“待开发或待验证事项”列示；功能实现不代表已完成生产环境验收。

## 功能覆盖

| 功能域 | 已实现功能 | 待开发或待验证事项 |
| --- | --- | --- |
| 模型与运行时 | 本地模型快照、SHA-256 校验、外部模型引用、CPU 分类模型示例 | 断点导入、模型分片语义校验、运行时与设备兼容性认证、镜像仓库管理 |
| 服务部署 | 三类部署入口、类型化命令、配额预检、后台部署任务、独立就绪条件、诊断日志、部署模板、持续状态观测、阶段时间线 | LLM 认证模板、自动修复控制器、设备与推理引擎专属诊断 |
| 服务发布 | 历史修订、资源更新、版本回滚、停止与恢复、引用保护删除、百分比灰度、指标触发回退、网关 SSE 排空 | 发布审批、多网关协调排空、生产负载下的灰度与排空验证 |
| 集群与资源治理 | 单集群三节点、项目命名空间、整卡 GPU 资源声明、项目配额、节点禁止调度、项目资源池、全局资源申请量与容量视图、项目部署策略 | 节点排空与驱逐预检、GPU 与异构设备认证、生产网络隔离策略 |
| 原生资源 | 七类受限资源、服务端预检、部分失败记录、基于 UID 的回退保护 | 任意自定义资源（CRD）、原生对象更新与版本回滚、资源实时浏览能力扩展 |
| 服务编排 | 四类组合节点、决策路由、树形组合校验与执行、子调用记录 | 通用有向无环图（DAG）与共享节点、可视化拖拽映射、自定义融合插件、末端流式编排 |
| 网关与访问治理 | Chat、SSE、Embedding、Decision 接口，逻辑服务目录，API Key 授权与撤销，RPM 与估算 TPM 限制，预算控制，明确 HTTP 拒绝后的备用切换 | 网络超时场景下的精确一次切换、请求排队、完整租户与应用层次、组织级策略 |
| 用量与计费 | 上游用量结算、费率快照标识、父子调用去重、缺失用量核对、CSV 导出、计量审计 | 财务级费率版本管理、自动供应商账单对账、跨进程消息去重 |
| 身份与安全 | 密码哈希、会话管理、CSRF 防护、项目与角色隔离、凭据加密、Windows 访问控制、Kubernetes 受限凭据 | OIDC 与 LDAP 集成、KMS 与 HSM 集成、完整安全评审、企业密钥轮换制度 |
| 监控与运维 | 请求与操作记录、P95 延迟与首 Token 延迟（TTFT）及失败率指标、集群诊断、在线备份与恢复、启动脚本、资源指标采集、控制台告警、CPU 与并发自动伸缩 | GPU 硬件采集验证、外部告警渠道、控制面与数据面高可用、完整离线交付、升级迁移与灾备演练 |
| 分布式推理 | 实验性 SGLang / vLLM 跨节点 TP 模型组编排与引擎适配器、节点与共享卷预检、总配额、组状态、UID 保护清理及网页入口；实验性 vLLM/NIXL PD 分离、场景参数与路由协议 | 真实 GPU 推理验收、流水线并行（PP）、Ray 执行器、PD 真实 KV 传输与性能验收、组级自动恢复与专项性能验证 |

## 验证范围

| 验证对象 | 当前验证结果 | 验证边界 |
| --- | --- | --- |
| 控制台与网关 | 浏览器主流程、协议调用、权限隔离、用量计量及备份恢复已通过验证 | 不代表已完成生产安全与性能验收 |
| CPU 模型部署 | 容器化部署、多节点副本调度、修订与回滚、停止与恢复已通过真实集群验证 | 多节点副本不代表单模型跨节点分布式推理；本地容器节点不代表跨物理机故障域 |
| 监控与自动伸缩 | 真实 CPU 与内存采样、告警评估、副本数 2→3→2 自动伸缩已通过验证 | Metrics Server 近期快照不能替代生产历史监控 |
| 灰度与 SSE 排空 | 单控制台协议集成测试已通过 | 多网关协调与生产负载尚未验证 |
| 分布式模型组 | 清单与管理协议测试、浏览器入口及真实 Kubernetes 服务端 dry-run 通过 | 当前集群无 GPU，未验证真实模型加载、跨节点计算及性能 |
| GPU 指标 | 数据接口已通过协议适配测试 | 尚未完成真实 GPU 硬件采集与设备认证 |
| 外部模型调用 | 真实供应商调用结果见独立验收记录 | 合成协议测试不替代真实供应商调用 |
